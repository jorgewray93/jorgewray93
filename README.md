## Engineering principles

- **Solve the problem first.** Technology is a tool, not the objective.
- **Design for change.** Prefer clear boundaries and maintainable systems.
- **Keep humans in control.** AI should support accountable decisions.
- **Build with evidence.** Make assumptions explicit and validate before claiming success.
- **Protect trust.** Security, privacy, and reliable operations matter.
